Sr. Frontend Challenge | TermSheet 
TermSheet is a web application that allows real estate professionals to manage their real estate deals. We would like you to build a simple version of this application. Please use the below information to help guide you.
Requirements
Angular Version 17
Definition of Terms. In this example, a real estate deal consists of:
Deal Name
Purchase Price ($)
Address
NOI (Net Operating Income) ($)
Cap Rate = NOI / Purchase Price (%)
Description
Please create a simple web application in Angular, that does the following:
1) User will be taken to deal listing screen where user can see a table of pre-filled deals (if you want to create a mock API, feel free to do it)
2) User should have the ability to add one or more deals with the above details. Does not need to use API, nor does it need to survive a browser refresh meaning if the deal is added and I refresh the browser, it can disappear.
3) User should be able to filter the deal name and purchase price (greater/less than filter)
4) The application needs to have a login, meaning that user and password are required to authorize the user to navigate to the private pages
Submission
It is estimated that you’ll need approximately 3 hrs and no more than 6 hrs on this challenge.
The goal here is not to build a fully functional web application. We are instead trying to gauge your depth of experience with the Angular framework.
